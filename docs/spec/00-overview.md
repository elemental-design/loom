# 00 — Overview

## Pipeline

```
loom.tokens.ts ──► loom tokens build ──► generated/{palette.json, tokens.css, tokens.ts}
components/*.loom.tsx ─► loom extract ─► .loom/*.ir.json ─► loom gen web ─► dist/web/**
                    └──► loom lint
@loom/primitives (web impl) renders the same TSX directly in the browser (demo app, tests).
```

Source of truth = TSX + `loom.tokens.ts`. IR and generated files are always regenerable.

## Project layout (consumer; `examples/demo-ds` is one)

```
loom.config.ts
loom.tokens.ts                 source: seeds + roles
components/<Name>/<Name>.loom.tsx
components/<Name>/<Name>.compositions.ts   (optional)
generated/                     tokens output (committed)
.loom/                         IR output (committed)
dist/web/                      codegen output (committed in demo-ds for golden tests)
```

## `loom.config.ts`

```ts
import { defineConfig } from "@loom/compiler"
export default defineConfig({
  tokens: "./loom.tokens.ts",
  components: "./components/**/*.loom.tsx",
  out: { generated: "./generated", ir: "./.loom", web: "./dist/web" },
  web: { cnImport: "@/lib/utils", componentDir: "src/components/loom" },
})
```

## CLI (all commands exit non-zero on any error diagnostic)

| Command | Behavior |
| --- | --- |
| `loom tokens build` | `loom.tokens.ts` → `generated/*` |
| `loom extract` | components → `.loom/<Name>.ir.json` |
| `loom lint` | run lint rules, print diagnostics |
| `loom gen web [--check]` | IR → `dist/web/**`; `--check` compares to disk, writes nothing, fails on drift |

## Diagnostics

Format: `LOOM### <relative-path>:<line>:<col> <message>`, one per line, sorted by path/line. Severity `error` (exit 1) or `warn` (printed, exit 0). Code ranges: `LOOM0xx` tokens, `LOOM1xx` extraction, `LOOM2xx` lint, `LOOM3xx` codegen. Each task lists the codes it owns.

## Determinism rules (apply to every generated artifact)

- JSON: keys sorted recursively, 2-space indent, `\n` terminator.
- No timestamps, absolute paths, or machine-specific data.
- Hash = first 12 hex chars of sha256 of the source file bytes.
- Header on generated TS/CSS: `@generated by loom — do not edit. source: <relpath> hash: <12hex>`.
