# 04 — IR (v1)

One JSON file per component: `.loom/<Name>.ir.json`. Deterministic (see 00-overview). Produced by `loom extract` (T06); consumed by lint-time evaluation and codegen. The IR is never hand-edited.

## Types (`packages/compiler/src/ir/types.ts` — normative)

```ts
export interface IRComponent {
  irVersion: 1
  id: string                 // from `loom.id`
  name: string
  version: string            // from `loom.version`
  source: string             // repo-relative path
  hash: string               // 12-hex source hash
  doc?: string
  params: IRParam[]
  root: IRNode
}

export interface IRParam {
  name: string
  type: "string" | "number" | "boolean" | "enum" | "icon" | "action" | "child" | "array"
  required: boolean
  default?: string | number | boolean
  values?: string[]                                   // enum
  fields?: { name: string; type: "string" | "number" | "boolean" }[]  // array
  doc?: string
}

export type PrimitiveName =
  "HStack" | "VStack" | "ZStack" | "Spacer" | "Divider" | "Text" | "Image" | "Icon" | "Pressable"

export type IRNode =
  | { kind: "primitive"; id: string; type: PrimitiveName; props: Record<string, IRExpr>; children: IRNode[]; when?: IRExpr }
  | { kind: "component"; id: string; ref: string /* loom.id */; name: string; props: Record<string, IRExpr>; when?: IRExpr }
  | { kind: "repeat"; id: string; over: IRExpr; as: string; key: IRExpr; children: IRNode[]; when?: IRExpr }

export type IRExpr =
  | { lit: string | number | boolean | null }
  | { param: string }
  | { var: string }                                  // repeat loop variable
  | { get: IRExpr; field: string }                   // member access
  | { not: IRExpr }
  | { op: "===" | "!==" | "<" | ">" | "<=" | ">=" | "&&" | "||" | "+"; l: IRExpr; r: IRExpr }
  | { cond: IRExpr; then: IRExpr; else: IRExpr }
  | { lookup: Record<string, IRExpr>; key: IRExpr }  // object-literal index
  | { call: "String"; arg: IRExpr }
```

## Extraction rules

- **Node id:** index path from root: root `n0`, its second child `n0.1`, etc. `repeat` children continue the path.
- **Props:** every JSX attribute becomes `props[name]`. A bare boolean attribute (`<X clip />`) → `{lit:true}`. Prop names are kept exactly as authored.
- **Text content:** all JSX children of `Text` become `props.content`: single child → its expr; several → left-folded `+` (string literals as `lit`). `Text` has `children: []`.
- **Conditionals:** `{c && <El/>}` → `El` with `when: expr(c)`. `{c ? <A/> : <B/>}` → `A` with `when: c`, `B` with `when: {not: c}`. `{icon && …}` (truthiness of a param) → `when: {param:"icon"}`; evaluators use JS truthiness.
- **Repeat:** `{xs.map((x) => <El key={k}/>)}` → `{kind:"repeat", over: expr(xs), as:"x", key: expr(k), children:[El]}`; `key` is required (`LOOM107`).
- **Helper inlining:** a call `f(arg)` is replaced by `f`'s body with each parameter replaced by the argument expression (substitute on the IR tree, not text). Recursive helpers → `LOOM105`.
- **Casts / type annotations:** erased.
- **Default values:** `evalExpr` receives defaults merged with an explicit env; see below.

## Shared evaluator (`packages/compiler/src/ir/eval.ts`)

```ts
export type Env = { params: Record<string, Value>; vars: Record<string, Value> }
export type Value = string | number | boolean | null | Value[] | { [k: string]: Value }
export function evalExpr(e: IRExpr, env: Env): Value                 // JS semantics for truthiness and +
export function paramsOfExpr(e: IRExpr): Set<string>                 // param names referenced
export function domainOf(p: IRParam): Value[] | undefined            // enum → values; boolean → [false,true]; else undefined (open)
```

Missing lookup key → throw (`LOOM140`, "lookup has no entry for <key>"). Used by lint (T07) and codegen (T08).

## Extraction diagnostics (owned codes)

`LOOM101` unsupported prop type · `LOOM102` JSX spread · `LOOM103` fragment · `LOOM104` unsupported expression · `LOOM105` impure/recursive helper · `LOOM106` banned construct (hooks, classes, loops, `let`/`var`, async, try/throw) · `LOOM107` `.map` without `key` · `LOOM108` missing `loom` export / bad id · `LOOM109` file/function name mismatch · `LOOM110` unknown JSX element (not a primitive or imported loom component) · `LOOM140` evaluation error.
