# T02 — Token emitters + `loom tokens build`

**Goal:** `loom tokens build` reads `loom.tokens.ts` and writes `generated/{palette.json,tokens.css,tokens.ts}`.

**Read:** `docs/spec/01-tokens.md` (Emitted files, shadcn alias table), `docs/spec/00-overview.md` (config, determinism, CLI).
Before coding: skim ui.shadcn.com/docs/theming for current variable names (see spec note). Do not change the alias table; extra vars are fine.

## Create / modify
- `packages/compiler/src/tokens/emit-json.ts`, `emit-css.ts`, `emit-ts.ts` — each a pure `(def, palette) => string`.
- `packages/compiler/src/tokens/build.ts` — `buildTokens(cwd): Promise<Diagnostic[]>`: load config (`loom.config.ts` via `tsx`/`jiti`-style dynamic import — use `tsx`'s `tsImport` or `import()` under the `tsx` runtime), load tokens, validate (T01), build palette, contrast check, emit, write. If any error diagnostic: write nothing.
- `packages/compiler/src/config.ts` — `defineConfig` + loader (shape in 00-overview).
- Wire `loom tokens build` in `src/cli.ts`; print diagnostics; exit 1 on errors.
- `examples/demo-ds/loom.config.ts`, `examples/demo-ds/loom.tokens.ts` (exact content from 01-tokens.md), and commit the generated output in `examples/demo-ds/generated/`.
- Tests: `packages/compiler/src/tokens/emit.test.ts`.

## Details
- Header (CSS/TS): `@generated by loom — do not edit. source: loom.tokens.ts hash: <12hex>`; JSON has no header (no comments) — omit hash there.
- Emit order is fixed: roles in definition order, then `transparent`; ramps in seed order accent, neutral, danger.
- `tokens.css` structure exactly as in spec (`:root`, `.loom-typography-*`, `@theme inline`). Colors lowercase hex. kebab-case via a single shared `kebab()` helper.
- `tokens.ts` module augmentation is the contract with `@loom/primitives` (T03). Interface name `LoomTokens`, keys `color|spacing|radius|typography`.

## Acceptance
- `pnpm --filter @loom/compiler test` includes: snapshot of `tokens.css` for the demo tokens (use vitest `toMatchFileSnapshot`), assertion that `--primary` aliases `--loom-color-accent`, that every role has both `--loom-color-*` and `--color-loom-*`, JSON keys sorted, running `buildTokens` twice yields identical bytes, a failing contrast def writes nothing.
- `pnpm --filter demo-ds exec loom tokens build` (or `tsx ../../packages/compiler/src/cli.ts tokens build`) regenerates files with **no git diff** after the first commit.
- `generated/tokens.ts` typechecks (`pnpm typecheck`).

Dark mode, Tailwind config file, Figma/RN emitters, watching.
